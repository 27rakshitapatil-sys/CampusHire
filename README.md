# 🎓 CampusHire

CampusHire is a full-stack **Campus Recruitment & Job Portal** that connects students and recruiters through a centralized platform for job discovery, applications, and recruitment management.

## 🚀 Live Demo

🌐 https://campushire-ckre.onrender.com

## ✨ Features

### 👨‍🎓 Students
- Register and manage profile
- Upload resume and skills
- Search and filter job opportunities
- Apply for jobs with resume and cover letter
- Track application status
- Receive notifications and shortlist email updates

### 👨‍💼 Recruiters
- Register and access recruiter dashboard
- Create and manage job postings
- View and review applicants
- Shortlist, reject, or select candidates

## 🛠️ Tech Stack

- **Backend:** Python, Django 6.1
- **Frontend:** HTML, CSS, JavaScript
- **Database:** PostgreSQL
- **Email:** SMTP
- **Deployment:** Render
- **Version Control:** Git & GitHub

## 🔐 Key Functionality

- Role-based student and recruiter access
- Secure authentication
- Job search and filtering
- Duplicate application prevention
- Application status management
- In-app notifications
- Email notifications
- PostgreSQL database integration

## 🎯 Objective

To simplify the campus hiring process by providing students with an easy way to discover and apply for opportunities while giving recruiters an organized platform to manage candidates.
